# FARO — Mockup / Diseño Visual

Carpeta de maquetas HTML estáticas para el diseño visual de FARO.
**No tiene ninguna relación con `faro-platform` (el proyecto real).**

## Estructura
```
faro-mockup/
├── assets/
│   ├── css/      ← estilos compartidos
│   ├── js/       ← scripts opcionales
│   └── img/      ← imágenes y assets
├── index.html    ← página principal / navegación entre maquetas
└── [pantalla].html  ← cada pantalla diseñada
```

## Cómo ver
Abrir cualquier `.html` directamente en el navegador — no requiere servidor.
